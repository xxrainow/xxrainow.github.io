# Studio 영상 교체 안내

이 문서는 수정자를 위한 한글 안내입니다. 웹페이지에서 불러오거나 표시하지 않습니다.
`projects.js`의 한글 주석도 화면에 표시되지 않습니다.

현재 카드 제목은 `Demo 01`~`Demo 30`, 분류와 설명은 `Demo`이며 연도는 비어 있습니다.
영상 파일 자체는 기존 MotionSites 데모 영상을 유지합니다. 영상 안에 들어 있는 원본 글자나 로고는 바뀌지 않습니다.

## 어디를 수정하나요?

`studio/projects.js`를 여세요. 객체 `{ ... }` 하나가 카드 하나입니다.

```js
{
  video: './media/my-project.mp4',
  title: '프로젝트 이름',
  category: '작업 분류',
  year: '2026',
  description: '만든 목적, 핵심 기능, 내가 맡은 역할, 사용 기술과 결과를 짧게 설명합니다.',
},
```

위의 한글은 작성 예시입니다. 실제 데이터의 `title`, `category`, `description`에 한글을 넣으면 그 내용은 화면에 보입니다.
영어 화면을 유지하려면 실제 값은 영어로 작성하고, 한글 메모는 `// 주석`으로 남기세요.
주석과 이 문서는 렌더링되지 않지만 공개 레포의 소스에서는 읽을 수 있으므로 비공개 정보는 적지 마세요.

## 각 항목에 넣을 정보

| 항목 | 넣을 정보 | 화면에서 보이는 위치 |
| --- | --- | --- |
| `video` | 작업을 보여주는 MP4 파일 경로 또는 영상 직접 주소 | 구체, 그리드, 확대 미리보기의 영상 |
| `title` | 작업 이름 | 마우스를 올렸을 때, 카드 아래, 확대 설명 |
| `category` | WebGL, AI, Web Development, UX/UI, Motion 등 작업 분류 | 카드의 작은 칩, 제목 옆의 분류 |
| `year` | 작업을 만든 연도. 예: `'2026'` | 분류 옆. `''`로 두면 생략 |
| `description` | 프로젝트 설명. 목적 → 핵심 기능 → 본인 역할 → 기술 → 결과 순서 권장 | Gallery에서 영상을 다시 선택했을 때와 Projects 팝업 |

추가로 `github`와 `demo`를 지원합니다. `github`는 **Code**, `demo`는 **Live Demo** 버튼으로 표시합니다. 카드 아래·Gallery 상세 설명·Projects 상세 창에 나타나며 새 탭으로 열립니다. 빈 값은 버튼을 숨깁니다. `role`, `techStack` 등 그 밖의 필드는 별도 UI를 구현하거나 `description`에 적어주세요.

## 영상 없이 GitHub·배포 주소만 등록하기

```js
{
  video: '', // 생략해도 됩니다.
  title: 'My Project',
  category: 'Development',
  year: '2026',
  description: 'What I built, my role, and the result.',
  github: 'https://github.com/xxrainow/my-project',
  demo: 'https://my-project.example.com',
},
```

영상이 없으면 프로젝트 이름을 담은 정적 카드가 표시됩니다. GitHub와 배포 주소는 http 또는 https 전체 주소로 입력하세요. 클릭 가능한 가짜 예제 주소를 만들지 말고, 아직 주소가 없다면 빈 문자열로 두세요. 한글 안내 주석은 웹 화면에 표시되지 않습니다.

## 작업 종류에 따라 어떤 영상을 넣을까요?

- 웹·앱: 대표 화면에서 핵심 기능을 실제로 사용하는 화면 녹화.
- AI·개발: 입력 → 실행 과정 → 결과를 보여주는 데모.
- UX/UI: Figma 프로토타입이나 주요 화면 전환을 녹화한 영상.
- 공모전·팀 작업: 결과물을 요약한 짧은 소개. 설명에는 팀 전체 작업과 내 역할을 구분.
- 개인 실험: 셰이더, 커서 효과, 애니메이션 등이 움직이는 모습. 현재 무지개 홈도 한 개의 작업으로 넣을 수 있음.

특정 번호에 정해진 주제는 없습니다. 앞쪽에 가장 먼저 보여주고 싶은 작업을 넣으세요.

## 내 영상 파일을 넣는 순서

1. `studio` 안에 `media` 폴더를 만듭니다.
2. 그 안에 예를 들어 `rainbow-playground.mp4`를 넣습니다.
3. 해당 카드의 `video`를 `'./media/rainbow-playground.mp4'`로 바꿉니다.
4. 나머지 네 항목을 작성한 뒤 브라우저에서 새로고침합니다.
5. 배포하려면 수정한 데이터 파일과 새 MP4 파일을 함께 커밋하고 푸시합니다.

경로는 `projects.js`가 있는 `studio` 폴더 기준입니다. 파일명 끝의 `.mp4`도 직접 써주세요.
기존처럼 원본 서버 주소가 자동으로 붙지 않으므로 외부 서버와 로컬 파일을 카드마다 섞어서 사용할 수 있습니다.
외부 영상을 쓸 때는 `https://example.com/preview.mp4` 같은 **영상 파일 직접 주소**를 넣어야 합니다. 유튜브 시청 페이지 주소는 지원하지 않습니다. WebGL 영상 텍스처를 위해 외부 서버의 CORS 허용도 필요합니다.

권장 영상은 가로 16:9 MP4(H.264)입니다. 짧고 용량이 작은 반복 영상이 적합하며 음성 없이도 이해되게 만드세요. 영상은 무음으로 재생됩니다.
현재 화면은 16:9를 기준으로 하므로 다른 비율의 영상은 미리 16:9로 편집하는 편이 좋습니다.

## 카드 순서와 개수

- Gallery: 배열의 앞 20개.
- Projects: 배열의 앞 24개.
- 25~30번: 현재 화면에 나오지 않는 예비 항목.
- 표시 번호는 배열 순서대로 자동으로 붙습니다. 객체를 위아래로 옮기면 순서가 바뀝니다.
- 24개보다 적게 남겨도 동작하지만, Gallery는 20개를 기준으로 배치·인트로를 구성하므로 적은 수로 재구성할 때는 레이아웃 조정이 필요할 수 있습니다.
- 표시 개수 자체를 바꾸려면 `studio.js`의 `projects.slice(0,20)`과 `projects.slice(0,24)` 및 구체 배치 코드를 함께 조정하세요.

## 확인하기

저장소 최상위 폴더에서 실행합니다.

```sh
python3 -m http.server 4175
```

`http://localhost:4175/studio/`로 접속하세요. 파일을 더블클릭한 `file://` 주소에서는 ES 모듈이 차단될 수 있습니다.

- Gallery에서 제목과 확대 설명 확인.
- Projects에서 칩·제목·연도와 팝업 설명 확인.
- 새 영상이 정상 재생되고 가로세로 비율이 맞는지 확인.

실제 작업으로 바꾼 뒤에는 `index.html`의 데모·MotionSites 출처 문구와 `studio.js`의 데모 관련 문구도 실제 콘텐츠에 맞게 수정하세요. 아직 원본 데모가 남아 있다면 출처 표시는 유지하세요.
